## فعّل تسجيل الدخول بجوجل (اختياري — الموقع يعمل بدونه)

> الموقع يعمل بالكامل لزائر جديد **بدون** Firebase: ٥٢٥ رابطاً والبحث والأداة
> كلهم يعملون. Firebase يضيف فقط: تسجيل الدخول، ولوحة التحكم، والمزامنة.

1. افتح <https://console.firebase.google.com> ← Add project
2. **Authentication** ← Sign-in method ← **Google** ← فعّل
3. **Authorized domains** ← أضف `monstorjohan-png.github.io`
4. **Project settings** ← General ← SDK setup and configuration ← انسخ القيم
5. افتح `assets/js/config.js` واستبدل القيم:

```js
firebase: {
  apiKey: "القيمة_الحقيقية",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
}
```

6. **Firestore Database** ← Create database ← Production mode
7. انشر قواعد الأمان:

```powershell
npm install -g firebase-tools
firebase login
firebase init
firebase deploy --only firestore:rules
```

8. **اجعل نفسك مشرفاً:**
   - افتح **Authentication** ← Users ← اضغط على حسابك ← انسخ **UID**
   - في Firestore أنشئ مجموعة `admins` وأضف مستنداً باسم هذا الـ UID
9. ضع الـ UID في `config.js`:

```js
adminUids: ["UID_الخاص_بك"]
```

10. أعد النشر على Netlify أو Vercel

## قيود يجب معرفتها

### ١. التحديث يدوي وليس تلقائي

الموقع **لا يبحث في الإنترنت بنفسه** ولا يضيف مواقع من تلقاء نفسه. التحديث يتم بطريقتين:
- من لوحة التحكم: تضيف أو تعدّل أو تحذف الروابط بنفسك
- من الزوار: يرسلون روابطهم وتُراجعها قبل النشر

البحث التلقائي عن مواقع جديدة يتطلب خدمة خارجية مدفوعة أو نظاماً معقداً، وهذا غير ممكن مجاناً.

### ٢. أداة التحميل لا تحمّل من موقعك — وده مثبت بالاختبار

هذه أهم نقطة يجب فهمها بوضوح، وليست رأياً:

**لماذا لا يمكن لموقع ثابت أن يحمّل فيديو؟**
التحويل يحتاج برنامجاً اسمه `yt-dlp` يعمل على **خادم**. أي موقع مبني بـ
HTML و JavaScript فقط لا يستطيع تشغيله. قيد تقني في المتصفح نفسه، لا نقص في الموقع.

**الدليل العملي (تم فحصه حيّاً):**

```
$ node tools/test-cobalt-api.js
POST https://api.cobalt.tools/  →  HTTP 400
{"error":{"code":"error.api.auth.jwt.missing"}}
```

حتى واجهة Cobalt نفسها — وهي الأفضل في العالم لهذا الغرض — **ترفض أي طلب بلا مفتاح**.
فلا يوجد أي موقع مجاني ثابت يمكنه التحميل نيابةً عنك.

**ما تفعله الأداة فعلاً:**
1. تتحقق من الرابط والمنصة (٦ منصات مدعومة)
2. **تفحص صحة ٤ خدمات تحميل حيّاً** وتعرض للمستخدم أيها يعمل الآن
3. تعطي خطوات مرقّمة وزر نسخ بضغطة واحدة

الخدمات المفحوصة حيّاً:

| الخدمة | الحالة | الحكم |
|---|---|---|
| **Cobalt** | 200 | ★ موصى به — مفتوح المصدر بلا إعلانات |
| 9Convert | 200 | احتياطي — يحتوي إعلانات |
| TikMate | 200 | احتياطي — يحتوي إعلانات |
| YT1s | 200 | احتياطي — يحتوي إعلانات |

> **`loader.to` حُذف** — فحصناه حيّاً فوجدناه يحوّل إلى شبكة إعلانات تعرض أشرطة
> تحميل وهمية وتطلب تثبيت برامج. لا نوجّه أحداً إلى مواقع كهذه.

**إن أردت تحميلاً حقيقياً بلا حدود:** شغّل نسخة Cobalt خاصة على خادم صغير
(نحو ٤ دولارات شهرياً على DigitalOcean) ثم ضع رابطها في `config.js` في
`download.selfHosted`، وستظهر تلقائياً كخيار أول في الأداة.

المنصات المدعومة: **YouTube · TikTok · X/Twitter · SoundCloud** (فيديو وصوت)
و **Facebook · Instagram** (فيديو فقط — استخراج الصوت غير مدعوم فيها).

#### تفعيل التحميل الحقيقي (الطريقة الوحيدة الكاملة)

```bash
# على خادم VPS (DigitalOcean 4$ شهرياً، أو Hetzner، أو AWS Lightsail)
docker run -d -p 9000:9000 \
  --name cobalt \
  -e API_URL=http://localhost:9000/ \
  imputnet/cobalt:latest
```

ثم ضع رابطه في `assets/js/config.js`:
```js
selfHosted: "https://your-cobalt.example.com/",
```

واعمل نشراً جديداً: `node tools/deploy-github.js jami3-rooab`

ستظهر نسختك تلقائياً كأول خيار في الأداة، وستكون بلا حدود وبلا إعلانات.
راجع <https://github.com/imputnet/cobalt> لخطوات التثبيت الكاملة.

### ٣. فحص الروابط آلي وليس كاملاً

يفحص الموقع ١٥ نمطاً خطيراً تلقائياً:
ملفات التنفيذ، روابط javascript و data، عناوين IP، روابط localhost، مختصرات الروابط، بيانات الدخول في الرابط، المسافات، البروتوكولات الخطرة.

لكنه **لا يفحص محتوى الموقع نفسه**. المراجعة اليدوية قبل النشر ضرورية.

### ٤. بعض الروابط قد تخالف قوانين محلية

روابط مثل `Libgen` و `Kutub` متضمنة **مع تحذير واضح** لأنها قد تخالف قوانين التوزيع في بعض الدول. استخدمها على مسؤوليتك.

## المدققات

شغّل **المدقق الشامل** قبل أي نشر:

```bash
node tools/audit-all.js
```

يشغّل ثلاث مدققات ويخرج ملخصاً واحداً:

| المدقق | ما يفحصه |
|---|---|
| `tools/audit-data.js` | صيغة الرابط (https فقط)، التكرار، الأوصاف الفارغة أو التالفة، الأقسام غير المعروفة، اللغات، الأنواع، الحروف الصينية |

النتيجة المطلوبة: `النتيجة: كل المدققات نجحت ✓`

كل مدقق **يُنهي التنفيذ برمز خطأ `exit 1`** عند وجود مشكلة، فيمكن ربطها بأي نظام CI/CD تلقائي.

